# 数独推演器

基于 Vite、React 和 TypeScript 的可解释数独求解器。求解器每次只应用
一个当前盘面可用、权重最低的技巧；任何落数或候选消除之后都会从裸单开始
重新扫描（Waterfall）。

## 技巧体系

- 基础：裸单、隐性唯一数
- 区块交叉：指向、认领
- 候选数组：裸/隐性数对、三数组、四数组
- 基础鱼：X-Wing、Swordfish、Jellyfish
- 翼形：XY-Wing、XYZ-Wing
- 链：简单染色、X-Chain、XY-Chain、通用 AIC 强弱链
- 完备兜底：带因果父节点的西尾强制链、嵌套强制网

高级技巧只提出候选消除，不会直接写入一个隐藏搜索得到的终盘。强制网会为
假设候选建立反证分支，只有所有相关分支都产生可检查矛盾时才删除候选；
随后调度器立即回到最低权重技巧。

西尾链不会再把按时间发生的基础落数串成伪链。每个真假候选都记录实际父
节点：真候选通过弱链接排除同格或同单位候选；某格或某单位的其余位置均为
假时，唯一剩余候选通过强推导为真。界面据此绘制实线/虚线，并标出最终冲突
所在的格、行、列或宫。

固定且有限的命名技巧集在理论上不能覆盖所有唯一解数独。为了满足完备性，
最后一级使用无界的 proof-producing forcing net。它展示的是逻辑反证树，
不会把试算答案伪装成推理步骤；但其最坏情况计算复杂度与穷举搜索等价。这是
“所有唯一解”与“有限人类技巧”之间不可回避的边界。

求解内核还会在每一步前后检查候选有效性、空候选格、单位内数字无位置、
重复状态和最终行列宫约束。候选输入模式可用于描述已经消减过的中间局面：
有手工候选的格子会把这些候选作为额外约束，其余格子仍自动计算候选。

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm run lint
npm test
```

求解内核位于 `lib/sudoku`，不依赖 React 或构建框架。后续可以在保持
TypeScript 接口稳定的前提下，逐步将性能敏感模块替换为 Rust/Wasm。
