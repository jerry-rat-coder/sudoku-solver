# 无马数独（Anti-Knight）人类技巧库设计

> 目标：构建可扩展、可验证的无马数独人类技巧库，并集成到步骤播放器。
> 约束：**严格人类逻辑推导**——不使用回溯、暴力搜索或猜测；每一步可解释、可验证、可回放；
> 永远优先选择最简单的有效技巧（由技巧注册表的权重瀑布保证）。

## 0. 规则定义

无马数独 = 经典数独 + **马步互斥**：

> 两个单元格若构成国际象棋马步（日字：行差 2 列差 1，或行差 1 列差 2，共 8 个偏移方向），
> 则这两个单元格**不能包含相同的数字**。

记号：`a ↔ b` 表示格 `a`、`b` 马步互见。马步互见是对称关系；互见格在下文统称"互见"（peer）。

一个重要结构事实（后文多次用到）：

> **引理 0（二部性）**：马步图是二部图。马步每走一步，`(行 + 列)` 的奇偶性翻转，
> 因此不存在三个两两马步互见的格（无马步三角形）。
> 推论：无马专属"数组"技巧最多到**数对**；三格以上的互见组必须混合单位互见（行/列/宫），
> 属于后续扩展（见 §6）。

## 1. 资料调研结论

调研方式：开源项目代码检索（GitHub / grep.app）、理论站点与题库站点抓取。

| 来源 | 与无马技巧相关的结论 | 可验证性 |
| --- | --- | --- |
| `Hemant2059/sudoku`（本地 `sudoku/`） | 只有约束建模（`KNIGHT_MOVES` 8 偏移、DLX"边×数字"精确覆盖、回溯 `knightPeers`）；**无任何无马专属人类技巧**；其"人类管线"候选传播不含马步、最终偷看搜索解兜底 | ✗ 不可照搬（违反纯人类逻辑要求） |
| `SudokuMonster/SukakuExplainer`（Sudoku Explainer 增强版） | `Grid.java` 以 `antiVisibleCellIndex` 把马步格并入**可见格集合**，让全部经典人类技巧作用于扩展可见性 | ✓ 佐证"标准技巧复用"路线 |
| `tlandegger/pencil-guard`（sudoku.coach 自动消候选扩展） | 佐证社区共识的无马基础推理 = **落数后从马步互见格删除该候选**（传播层） | ✓ |
| `sigh/Interactive-Sudoku-Solver` | 把 `AntiKnight` 建模为若干 `AllDifferent` 组（搜索求解器，无人类技巧） | 参考约束建模 |
| puzzlemadness.co.uk「Anti Knight Sudoku」 | 规则表述与示例图（中心 5 排除 8 个马步格） | ✓ 规则来源 |
| sudoku.coach Campaign | 教学体系中无马属于"Sudoku Variants"章节，以规则传播 + 组合推理为主 | 参考 |

**结论**：社区对无马数独**没有统一的技巧命名体系**，被反复证实的只有两条：

1. 马步互见传播（落数 → 删马步候选）；
2. 把马步互见并入互见集合后，**标准技巧整体迁移**（SukakuExplainer 做法）。

因此本技巧库的处理原则（对应"不得臆造规则"）：

- **不发明花哨的专属名词**。专属技巧只收录能从规则出发给出**完整形式证明**的模式，
  命名沿用本项目既有体系（指向/认领/数对），以"马步-"前缀标识无马专属。
- 标准技巧一律**复用或扩展**，不重复实现（见 §3）。
- 资料不足或依赖唯一性假设的技巧**不实现**，只登记为扩展方向（见 §6）。

## 2. 技巧总体分类

| 层级 | 含义 | 处理方式 | 对应技巧 |
| --- | --- | --- | --- |
| A. 复用 | 标准技巧，逻辑与马步无关 | 零代码改动自动生效（互见/单位接口已参数化） | 裸单、隐性唯一数、区块摒除、2–4 数组、鱼形、翼形、染色、X-Chain、XY-Chain、AIC、西尾链、强制网 |
| B. 扩展 | 标准技巧的约束面扩大 | 扩展互见/传播/冲突检测；解释文案点名马步 | 候选传播、冲突检测、裸单解释、AIC/链的**弱链**自动包含马步互见 |
| C. 专属 | 只有马步约束才能推出的模式 | 新增技巧（category `antiknight`） | 马步指向、马步认领、马步数对 |
| D. 暂不实现 | 资料不足或假设过强 | 仅登记，不实现 | 马步数组（混合互见）、无马唯一矩形、无马专属鱼形 |

实现映射：`PuzzleVariant = 'classic' | 'x' | 'antiknight'`。
无马是 **peer 约束**（互见扩展），与对角线数独的 **unit 约束**（单位扩展）不同：

- `peersForVariant('antiknight')` = 经典互见 ∪ 马步互见 → 传播、`applyStep`、链推理**自动生效**；
- `unitsForVariant('antiknight')` = 经典 27 单位（马步不产生新单位）；
- `conflictCellsForValues` 原本只扫单位，**必须补马步重复检测**（见 §4.2）。

## 3. A 类：标准技巧复用清单（零重复实现）

以下技巧在实现中一律通过 `unitsOf(board)` / `peersOf(board)` / `commonPeers(cells, variant)` /
`cellsSeeEachOther(a, b, variant)` 取得互见关系，因此对无马模式自动正确：

| 技巧 | 权重 | 无马模式下的行为 |
| --- | --- | --- |
| 裸单 naked-single | 10 | 候选唯一即落数；候选唯一性已含马步排除（解释文案见 §4.4） |
| 隐性唯一数 hidden-single | 20 | 行/列/宫内唯一位置（马步不产生新单位，无对角线式变体） |
| 区块摒除 pointing/claiming | 30/31 | 结论与马步无关，复用 |
| 裸/隐 数对·三数组·四数组 | 40–65 | 单位内推理，复用（马步版数对见 §4.3） |
| 鱼形 X-Wing/Swordfish/Jellyfish | 80/110/150 | 行列结构技巧，复用 |
| 翼形 XY-Wing/XYZ-Wing | 90/100 | `commonPeers` 消除区自动包含马步公共互见格，**结论变强**，实现不变 |
| 简单染色、X-Chain、XY-Chain | 120/130/140 | 弱链判据 `cellsSeeEachOther` 自动含马步互见 |
| AIC 强弱链 | 160 | 弱链自动含马步互见（马步互见 = 同候选弱链）；**强链仍只来自双值格与单位共轭对**——这是正确的，马步约束单独不产生"恰有一真" |
| 西尾链 nishio-chain、强制网 forcing-net | 170+ | 蕴含图互见判据参数化，自动生效 |

> 注意：马步约束只产生**弱链**（不能同数），不产生强链。"两格同候选且马步互见"是一条弱链，
> 与"同单位同候选"的弱链在链推理中地位相同，无需任何专属实现。

## 4. C 类：无马专属技巧（新增实现）

每个技巧给出：**适用条件 → 逻辑证明 → 候选数消除规则 → 可视化方式**。
可视化统一走 `SolveStep` 字段，由棋盘/步骤面板既有高亮机制渲染（UI 风格与现状一致）：

| SolveStep 字段 | 棋盘呈现 |
| --- | --- |
| `focusCells` | 结论焦点格（琥珀高亮 `step-focus`） |
| `relatedCells` | 证据背景格（浅玉色 `step-related`） |
| `evidence` | 证据候选（玉色标记） |
| `removed` | 被删除候选（琥珀删除标记） |
| `links`（type `weak`） | 马步互见连线（`chain-link weak` 虚线） |
| `explanation` | 步骤面板三段式：前提 / 推理 / 结论 |

### 4.1 马步指向（knight-pointing，权重 35）

- **适用条件**：存在宫 `B`、数字 `d`、目标格 `X ∉ B`，使得
  `S = { p ∈ B | p 为空格且 d ∈ 候选(p) } ≠ ∅`，且 `∀p ∈ S：p ↔ X`（全部马步互见），
  同时 `X` 仍持有候选 `d`。
- **证明**：
  1. 宫 `B` 内必须恰好填入一个 `d`，故 `d` 必落在 `S` 中的某一格 `p*`；
  2. 由条件，`p* ↔ X`；若 `X = d`，则 `p*`、`X` 两个马步互见格同为 `d`，违反无马规则；
  3. 故 `X ≠ d`。∎
- **消除规则**：从 `X` 删除候选 `d`。
- **可视化**：`focusCells = [X]`；`relatedCells = B 的全部格子 ∪ S ∪ {X}`；
  `evidence = S 中的候选 d`；`removed = [{X, d}]`；`links = S 中每格到 X 的弱链（马步互见）`。
- **说明**：`|S| = 1` 时结论依然成立，但隐性唯一数（权重 20）会先行落数并自动传播，
  瀑布调度保证本技巧只在 `|S| ≥ 2` 时才有机会出现。

### 4.2 马步认领（knight-claiming，权重 36）

- **适用条件**：同 §4.1，但单位 `U` 换成**行或列**（宫版本即马步指向）。
- **证明 / 消除 / 可视化**：与 §4.1 完全同构（`relatedCells = U ∪ S ∪ {X}`）。
- **命名**：沿用"区块摒除（指向 = 宫→线，认领 = 线→宫）"的宫/线对偶习惯：
  宫发起的叫马步指向，行/列发起的叫马步认领。

### 4.3 马步数对（knight-pair，权重 42）

- **适用条件**：两格 `P ↔ Q`（马步互见），且 `候选(P) = 候选(Q) = {a, b}`（恰两个相同候选）。
- **证明**：
  1. `P ↔ Q`，故 `值(P) ≠ 值(Q)`；
  2. 两格候选都是 `{a, b}`，故 `{值(P), 值(Q)} = {a, b}`（一格 `a`、一格 `b`）；
  3. 设 `X` 与 `P`、`Q` **都互见**（行/列/宫或马步均可）。无论 `a` 落在 `P` 还是 `Q`，
     `X` 都与含 `a` 的格互见，故 `X ≠ a`；同理 `X ≠ b`。∎
- **消除规则**：从 `commonPeers(P, Q)`（同时互见两格的格子）删除候选 `a`、`b`。
- **可视化**：`focusCells = [P, Q]`；`relatedCells = commonPeers(P,Q) ∪ {P,Q}`；
  `evidence = P、Q 的候选 a、b`；`removed = 目标格的 a、b`；
  `links = P↔Q 弱链、P→X 弱链、Q→X 弱链`。
- **与裸数对的关系**：裸数对（权重 40）限定**同单位**两格、消除同单位其他格；
  马步数对的两格是**马步互见**（可能同宫，也可能跨单位），消除区是"共同互见格"，
  因此是独立模式、独立实现（约 40 行），不改动 `findNakedSubset`，避免重复实现。
- **为何没有马步三数组**：引理 0——马步图无三角形，不存在两两马步互见的三格；
  混合互见（部分单位、部分马步）的三数组见 §6。

### 4.4 B 类文案扩展（不是新技巧）

- **候选传播**：`createBoard` / `applyStep` 的候选排除从"行/列/宫互见"扩展到"互见含马步"；
  这是约束传播而非推理步骤，不产生独立步骤，效果体现在后续裸单/隐单等步骤中。
- **裸单解释**：前提句按变体点名互见来源——
  经典："同行、同列和同宫已经排除了其余数字"；
  对角线："……以及同对角线……"；无马："……以及马步互见的位置……"。
- **冲突检测**：`conflictCellsForValues` 在无马模式下补扫马步对（行/列/宫重复照旧），
  校验文案："盘面中存在同行、同列、同宫或马步互见的重复数字。"

## 5. 验证与回放机制

每一步都经过引擎中央校验（`validateProposedStep`）后才可入列：

1. **合法性**：落数必须是当前盘面的有效候选；消除项必须真实存在、不得重复；
2. **有效性**：步骤必须实际改变盘面（删至少一个候选或填一格）；
3. **一致性**：应用步骤后整盘重新校验（含马步冲突检测），出现矛盾即中止并报告；
4. **无环性**：盘面状态指纹去重，杜绝循环；
5. **瀑布调度**：每次盘面变化后从最低权重重新扫描，保证"最简单的有效技巧优先"；
   高权重技巧（AIC、西尾链、强制网）只在全部命名技巧失效后才登场。

回放：每步携带 `snapshots` 快照与 `explanation` 三段式，播放器逐步展示
"技巧名 → 前提 → 推理 → 结论 → 盘面变化"，与经典/对角线模式完全一致。

测试（`tests/antiknight.test.mjs`）覆盖：

- 互见扩展与传播（落数后马步候选被删）；
- 马步重复冲突检测（无马报冲突、经典不报）；
- 三个专属技巧各自的构造用例：断言触发条件、消除位置、解释文案、`links` 马步弱链；
- 专属技巧在经典/对角线模式下绝不触发；
- 示例题端到端：全部 `status: 'solved'`、每步三段文案齐全、终盘无马步冲突、
  至少一步用到无马专属技巧、逐位瀑布重放一致；
- **示例题唯一性**：测试内置独立计数器（仅用于出题校验，不参与求解推理），
  验证每道示例在无马规则下恰好一个解。

## 6. 明确暂不实现（登记为扩展方向）

| 候选技巧 | 状态 | 原因 |
| --- | --- | --- |
| 马步数组（三格及以上混合互见组） | 待扩展 | 需"两两互见（单位或马步）+ 候选并集 = 格数"的组合搜索，模式复杂；引理 0 保证纯马步三格不存在 |
| 马步隐藏数对（对偶形式） | 待扩展 | 无单位承载"隐藏"语义，需以互见闭包重新定义，资料不足 |
| 无马唯一矩形（UR 类） | 不实现 | 依赖"题目恰一解"假设，超出纯规则推导 |
| 无马专属鱼形/链形命名 | 不实现 | 无可靠资料先例，不臆造 |
| 搜索兜底（DLX/回溯偷看参考解） | 不实现 | 违反"严格人类逻辑、不猜测"；卡住时诚实报告 `stuck` |

高级技巧路线（按要求"先简单后 AIC/强弱链"）：AIC、XY-Chain、染色在无马模式下已**自动**
获得马步弱链（§3），后续可做的增强是链解释文案中标注哪些链边来自马步互见，
以及引入互见闭包上的广义数组（§6 第一行）。
